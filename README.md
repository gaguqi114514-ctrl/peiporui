# 配泼睿 · 官方网站（非官方）

一个给朋友「配泼睿 / Paper Ray」做的整蛊个人网站。纯静态（HTML + CSS + JS），无任何依赖，双击即开。

## 页面

| 文件 | 内容 |
| --- | --- |
| `index.html` | 首页：巨幅姓名、实时状态、离谱数据面板、个人档案、技能条、名言跑马灯、好友控诉、通缉令预告、免责声明 |
| `wanted.html` | 通缉令：可点击盖章的 WANTED 海报、六宗罪、案发当日行踪、举报方式、原件扫描 |
| `gallery.html` | 黑历史图库：5 张照片 + 拍立得风格 + 点击放大灯箱（支持 ← → / Esc） |
| `honors.html` | 荣誉墙：9 个离谱奖项、虚构媒体报道、编年史、假装永远被拒的入会申请表单 |
| `404.html` | 走丢页面：给托管到服务器时用的彩蛋 |

## 彩蛋 / 交互

- 打开首页 1.3 秒后弹「系统检测到你在偷看」，「我错了」按钮会躲你三次。
- 键盘连按 `p p r`：天降毛巾与被窝。
- 右上角 🔊 可开关音效（WebAudio 合成，点击按钮 / 图片 / 卡片会响）。
- 通缉令海报点一下会「盖章」。
- 「打赏 ¥0.01」会掉金币，但钱不会到账。
- 页面标题在你切到别的标签页时会变成「别走！配泼睿还在被窝里等你」。

## 怎么发给朋友

1. **直接发压缩包**：把整个 `peiporui` 文件夹压缩后发过去，对方解压双击 `index.html` 即可。
2. **局域网整蛊**：在文件夹里运行 `python -m http.server 8000`，让同一 WiFi 的朋友访问 `http://你的IP:8000`。
3. **挂到网上**：把文件夹丢到 GitHub Pages / Netlify / Vercel（静态站，直接拖拽即可），得到链接后发群里；`404.html` 会自动成为 404 页面。

## 说明

- 图片在 `assets/` 里（毛巾形态、深夜网课、名场面表情包、田径场、通缉令原件）。
- 所有「罪名 / 数据 / 奖项 / 媒体评价」都是朋友之间的玩笑，纯属虚构，不含恶意。
- 想改文案：直接用记事本打开对应 `.html` 搜索文字替换即可；配色在 `style.css` 顶部的 `:root` 里。
- 想加图：把图片放进 `assets/`，在 `gallery.html` 里复制一个 `<figure class="shot">` 块，改 `src`、`data-full`、`data-title`、`data-desc` 即可。
