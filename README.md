## 🎮 游戏厅（6 台机器）

1. **保卫被窝**（`game.html`）：类植物大战僵尸。5×9 草坪，6 种道具（奶茶/毛巾/玩偶兔/眼镜/空调/闹钟炸弹），6 种敌人，8 波防守。左侧「守护目标」是配泼睿本人的拍立得照片，胜负结算也会弹出他本人的照片。
2. **打闹钟**（`whack.html`）：3×3 被窝洞，30 秒内敲掉冒出来的闹钟；金色闹钟 50 分；冒出来的**配泼睿真人头像**千万别敲（扣 20 分、扣 2 秒）。
3. **接外卖**（`catch.html`）：45 秒，用被子左右接外卖；🍜+10 / 🥟+15 / 🥤+20 / ⭐+30；🥊 扣命，⏰ 扣 5 秒。被子里探出的是他的真人头像。
4. **配泼睿扭蛋机**（`gacha.html`）：12 张**照片卡**（3 SSR / 3 SR / 6 R，含 3 张剪影卡），SSR 3%、十连必出 SR+、80 抽保底；重复卡自动变碎片，100 碎片换 1 抽。
5. **配泼睿浓度测试**（`quiz.html`）：8 题，满分 16，结果分四档，并配一张对应表情的真人照片。
6. **记脸挑战**（`memory.html`）：12 张牌、6 张真人照片各两张，步数越少越强。

所有分数、卡牌、抽卡券都存在 `localStorage`（键名前缀 `ppr-`），清空浏览器会重置。

## 彩蛋 / 交互

- 打开首页 1.3 秒后弹「系统检测到你在偷看」，「我错了」按钮会躲你三次。
- 键盘连按 `p p r`：天降毛巾与被窝。
- 右上角 🔊 可开关音效（WebAudio 合成，点击按钮 / 图片 / 卡片会响）。
- 通缉令海报点一下会「盖章」。
- 「打赏 ¥0.01」会掉金币，但钱不会到账。
- 切到别的标签页，标题会变成「别走！配泼睿还在被窝里等你」。
- 网址后面加 `?quiet=1` 可以关掉开场弹窗（方便截图 / 演示）。

## 怎么发给朋友

1. **直接发压缩包**：把整个 `peiporui` 文件夹压缩后发过去，对方解压双击 `index.html` 即可（所有游戏都能直接玩）。
2. **局域网整蛊**：在文件夹里运行 `python -m http.server 8000`，让同一 WiFi 的朋友访问 `http://你的IP:8000`。
3. **挂到网上**：把文件夹丢到 GitHub Pages / Netlify / Vercel（静态站，直接拖拽即可），`404.html` 会自动成为 404 页面。

## 文件说明

- `assets/`：9 张原图（毛巾形态、深夜网课、名场面表情包、田径场、通缉令、教授封面、深夜练功、三人对峙、呀嘞呀嘞）+ 3 张游戏用方形头像裁切（`face.jpg` 正面、`sleep.jpg` 裹毛巾、`yare.jpg` 呀嘞呀嘞）。
- `style.css`：全站样式，配色在顶部 `:root`。
- `script.js`：全站交互（弹窗、计数、音效、运势、商店、灯箱等）。
- `game.js` / `whack.js` / `catch.js` / `gacha.js` / `quiz.js` / `memory.js`：六个游戏的逻辑。
- 游戏里的配泼睿：保卫被窝的「守护目标」拍立得、打闹钟的真人头、接外卖的被子头、扭蛋机的照片卡、浓度测试的结果头像、记脸挑战的牌面——都是直接用 `assets/` 里的照片，没有额外素材。
- 想改文案：记事本打开对应 `.html` 搜索替换。
- 想加图：图片放进 `assets/`，在 `gallery.html` 里复制一个 `<figure class="shot">` 块，改 `src`、`data-full`、`data-title`、`data-desc`。
