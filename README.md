一个给朋友「配泼睿 / Paper Ray」做的整蛊个人网站。纯静态（HTML + CSS + JS），无任何依赖，双击即开。

## 小游戏「保卫被窝」

室友、宿管阿姨、快递小哥、辅导员正从右边冲进来，目标是把配泼睿叫醒。你要用宿舍里的一切守住他。

- **操作**：点卡槽 → 点草地格子种植；点天上掉下来的太阳收卡路里；`1–6` 选卡，`空格` 暂停，`Esc` 取消。
- **道具**：珍珠奶茶（产卡路里）、蓝毛巾（肉盾）、玩偶兔（扔袜子）、眼镜（双发高伤）、空调（减速）、闹钟炸弹（范围爆炸）。
- **敌人**：闹钟（快·脆）、室友、快递小哥（快）、拖鞋室友（肉）、宿管阿姨（重装）、辅导员（第 8 波 BOSS）。
- **目标**：撑过 8 波。输了配泼睿就会被叫醒。
- 最高分存在浏览器 `localStorage` 里（键名 `ppr-game-best`）。
- 所有角色都是 canvas 手绘矢量图，不依赖 emoji 字体（老 Windows 也不会显示成黑白方块）。
- 手机端建议横屏，棋盘可左右滑动。

## 彩蛋 / 交互

- 打开首页 1.3 秒后弹「系统检测到你在偷看」，「我错了」按钮会躲你三次。
- 键盘连按 `p p r`：天降毛巾与被窝。
- 右上角 🔊 可开关音效（WebAudio 合成，点击按钮 / 图片 / 卡片会响）。
- 通缉令海报点一下会「盖章」。
- 「打赏 ¥0.01」会掉金币，但钱不会到账。
- 切到别的标签页，标题会变成「别走！配泼睿还在被窝里等你」。

## 怎么发给朋友

1. **直接发压缩包**：把整个 `peiporui` 文件夹压缩后发过去，对方解压双击 `index.html` 即可（游戏也能直接玩）。
2. **局域网整蛊**：在文件夹里运行 `python -m http.server 8000`，让同一 WiFi 的朋友访问 `http://你的IP:8000`。
3. **挂到网上**：把文件夹丢到 GitHub Pages / Netlify / Vercel（静态站，直接拖拽即可），`404.html` 会自动成为 404 页面。

## 文件说明

- `assets/`：9 张图片（毛巾形态、深夜网课、名场面表情包、田径场、通缉令、教授封面、深夜练功、三人对峙、呀嘞呀嘞）。
- `style.css`：全站样式，配色在顶部 `:root`。
- `script.js`：全站交互（弹窗、计数、音效、图库灯箱等）。
- `game.js`：小游戏全部逻辑与手绘精灵。
- 想改文案：记事本打开对应 `.html` 搜索替换。
- 想加图：图片放进 `assets/`，在 `gallery.html` 里复制一个 `<figure class="shot">` 块，改 `src`、`data-full`、`data-title`、`data-desc`。
